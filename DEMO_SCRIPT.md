# Daytown demo, 90 seconds or less

Use fictional tasks, close private windows and keep AI voice off until needed. Start the local server and application with npm start; Chrome's normal Google new tab stays unchanged.

| Time | Show and say |
| --- | --- |
| 0–10 s | Show the small pixel workbench. “When my coding agent is busy, I lose track of my own next step. Daytown keeps one manageable step beside me.” |
| 10–27 s | Hold the mic: “Fix auth tests tomorrow at ten, review PR 42 Friday at two.” Show the transcript, correct a word if needed, point to the explicit London deadlines, then Save tasks. |
| 27–40 s | Connect Codex once. The same selected pet works at the desk. Pin workbench and put it in the corner over a public, non-playing YouTube page. Empty space is transparent. |
| 40–55 s | Enable AI voice or show the reminder sign. Use Demo controls to advance time; display “Demo clock accelerated” in the recording. The task note warms and the pet becomes hungry, then sick. |
| 55–68 s | Trigger death. The ghost rises and a kind epitaph enters the permanent graveyard. A new egg waits. |
| 68–80 s | Finish one tiny step. Show the egg hatch, feeding and fireworks. “Finishing one small thing is enough to begin again.” |
| 80–90 s | Show the deadline review and corner workshop once more. “Codex built and reviewed independent lanes. Its reminder review caught events lost when all windows were closed; replay and atomic delivery claims now have tests.” |

Export at no more than 90 seconds, verify playback and duration, and check the repository link anonymously. This document is a recording guide, not a completed video.
